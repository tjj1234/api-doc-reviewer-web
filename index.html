在浏览器里跑一遍你的 API 文档，看它是否经得起 AI agent 消费 —— 输出检查什么 · 不符合的后果 · 应如何修改。

纯浏览器运行 文档不上传服务器 默认不接模型也能出报告

1 · 输入文档

支持 OpenAPI 3.x / Swagger 2.0（JSON 或 YAML），也支持纯散文文档。

选择本地文件，内容只在本机解析，不会上传。

支持 OpenAPI JSON/YAML 文件地址、GitHub 文件页（会自动转成 raw）、以及文档站首页（会自动探测 /openapi.json 等常见路径）。

公共代理是尽力而为：可能限流、失效，也可能不返回。目标站点未开放跨域时，直连会被浏览器整个拦掉（这是浏览器安全模型，不是本页故障）。使用代理时文档内容会经过第三方服务器 —— 敏感文档请勿勾选，改用粘贴或上传。

高级 · 自定义 CORS 代理（最可靠）

{url} = 已编码的目标地址，{rawurl} = 原样地址。填写后会被最先尝试。自建一个 Cloudflare Worker 代理只需几行代码，比任何公共代理都稳。
